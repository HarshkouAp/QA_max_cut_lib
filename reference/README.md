# Исходный исследовательский архив

Каталог `RQAOA_main` — распакованная база кода, из которой переносится
функциональность библиотеки.

- Архив: `RQAOA_main.rar`
- SHA-256 архива: `b4c684a5d4da469adc25bd99a405e402892d1a2524465e4c97ab6229c71a4aed`
- Python-файлов: 89
- Объём: 25 548 строк (по статическому аудиту архитектуры)

Каталог включён в проект **только для чтения и сверки**. Пакет
`QA_max_cut_lib` не импортирует эти модули и не зависит от них. Имена,
классы и поведение исходников используются как источник исследований;
ошибки, отмеченные в архитектуре, не переносятся автоматически.

При переносе каждого семейства фиксируется карточка соответствия:
исходный файл → новое имя → заменённые компоненты → исправления → проверки.

**Проверка целостности:** распаковка архива и каталог `reference/RQAOA_main`
содержат по 89 Python-файлов; SHA-256 всех файлов совпадает (0 расхождений).
