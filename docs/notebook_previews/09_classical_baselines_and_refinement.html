Classical baselines and exact refinement¶

Version 0.1.0rc2. The notebook exercises Goemans–Williamson (SDP + rounding), classical simulated annealing, exact conditional re-optimization of a block and the base solver → refiner wrapper.

All methods run on CPU. Annealing num_reads are not quantum shots. E=-C, so a good annealing value and the global cut are compared in the same units.

1. BQM sign and the complete assignment¶

A positive edge prefers different spins, a negative one prefers equal spins. An isolated vertex is still present in the result.

In [2]:
for weight in (2.0, -2.0):
    graph = WeightedGraph([(10, 30, weight)], nodes=[10, 30, 80])
    config = tools.load_json(PROJECT / "configs/solvers/simulated_annealing_cpu.json")
    config["num_treads"] = 1
    config["parameters"].update(num_reads=4, num_sweeps=16)
    config["limits"] = {"anneal_reads_total": 4, "anneal_sweeps_total": 64}

    metrics = tools.analyze_solution(graph, solution)

    assert set(solution) == {10, 30, 80}
    assert metrics["cut_value"] == graph.cut_value(solution)

2. ExactCPU as a small-scale reference¶

ExactCPU solves the full graph, not a block. Its C serves as a quality reference only for this small problem; the GW cut is not a reference by itself.

3. Goemans–Williamson¶

The SDP value is the numerical value of the relaxation, not a certified upper bound. Rounding uses independent hyperplanes.

In [4]:

5. The conditional FineTuning problem¶

Block S={10,30} has boundary fields at t_80=+1. Fixing one internal spin loses the conditional optimum; both spins are enumerated.

In [6]:
conditional_graph = WeightedGraph(
    [(10,30,1),(10,80,4),(30,80,3)], nodes=[10,30,80]
)
refiner_config = {
    "type": "exact_block",
    "parameters": {"max_size": 8, "batch_size": 4, "max_passes": 1},
    "selector": {"type": "explicit_blocks", "parameters": {"blocks": [[10,30]]}},
}
refiner = ExactBlockRefiner(refiner_config)
conditional_solution = refiner.refine(
    conditional_graph, {10:1,30:1,80:1}
)
print(conditional_solution, conditional_graph.cut_value(conditional_solution))
print("gain:", refiner.last_refinement["gain"])
assert conditional_solution == {10:-1,30:-1,80:1}
assert conditional_graph.cut_value(conditional_solution) == 7.0

6. Sequential application of blocks¶

Two independent local improvements cannot be added together. S1={10} and S2={30} both propose gain=1 on the old environment, but applying them together gives C=-4. A sequential refiner accepts only the first correction and recomputes the fields.

In [7]:
sequential_graph = WeightedGraph(
    [(10,30,3),(10,80,-2),(30,80,-2)], nodes=[10,30,80]
)
sequential_config = {
    "type": "exact_block",
    "parameters": {"max_size": 8, "batch_size": 4, "max_passes": 2},
    "selector": {"type": "explicit_blocks", "parameters": {"blocks": [[10],[30]]}},
}
sequential = ExactBlockRefiner(sequential_config)
sequential_solution = sequential.refine(sequential_graph, {10:1,30:1,80:1})
print(sequential_solution, sequential_graph.cut_value(sequential_solution))
assert sequential_graph.cut_value(sequential_solution) == 1.0

{10: -1, 30: 1, 80: 1} 1.0

7. Wrapper around a quantum base solution¶

The base record is saved separately. Angles, expected energy and quantum distributions belong to base_run, not to the classically improved assignment.
