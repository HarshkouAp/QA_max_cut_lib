QAOA-in-QAOA: block patterns and global orientations¶

Version 0.1.0rc2. The notebook demonstrates the base hierarchy: a local spin pattern inside a block, one free block orientation, the exact metagraph and the reconstruction of the source vertices.

This is not LS-RQAOA: what is selected here is a whole discrete block pattern, not a pair correlation. The local cut and the constant part Delta b are different quantities.

1. One block: pattern and flip¶

First the exact formula is checked on the control graph from the assignment. Blocks [10,30] and [80,101] have patterns (+1,-1). The metagraph holds the weight -2, Delta b=10, and C_original=Delta b+C_meta for all four orientations.

In [2]:
graph = WeightedGraph(
    [(10,30,2),(80,101,3),(10,80,5),(10,101,1),(30,80,4),(30,101,-2)],
    nodes=[10,30,80,101],
)
blocks = [(10,30),(80,101)]
patterns = {10:{10:1,30:-1}, 80:{80:1,101:-1}}
meta, delta_b, records = project_blocks(graph, blocks, patterns)
print("meta nodes:", meta.nodes)
print("meta edges:", meta.edges)
print("Delta b:", delta_b)
for tau10, tau80 in ((-1,-1),(-1,1),(1,-1),(1,1)):
    solution = {
        10: patterns[10][10]*tau10, 30: patterns[10][30]*tau10,
        80: patterns[80][80]*tau80, 101: patterns[80][101]*tau80,
    }
    print(tau10, tau80, graph.cut_value(solution), delta_b + meta.cut_value({10:tau10,80:tau80}))
assert meta.edges == ((10,80,-2.0),)
assert delta_b == 10.0

2. Several levels of real QAOA¶

At every level the local problems solve only the induced block. After readout the pattern is normalized by the anchor, and GraphReducer applies N_l-K exact constraints to the whole current graph.

3. CPU parallelism through the CLI¶

Jupyter on Windows cannot always start a spawn pool safely from the main notebook. The real parallel path is therefore exercised through the importable CLI in a separate process. It is the same coordinator, not a different algorithm.

In [4]:
parallel_config = deepcopy(config)
parallel_config["num_treads"] = 2
parallel_config["parameters"]["max_levels"] = 2
with tempfile.TemporaryDirectory(prefix="hierarchy_cli_") as tmp:
    cfg_path = Path(tmp) / "parallel.json"
    cfg_path.write_text(json.dumps(parallel_config), encoding="utf-8")
    command = [
        sys.executable, "-m", "QA_max_cut_lib.solvers.qaoa_in_qaoa_cpu",

4. Shared readout budget¶

For best_of_shots the problem minimum equals its M. All minima of the next level are reserved before it starts. The reservation is not doubled per block.

5. Optional NVIDIA section¶

This section runs only when CuPy and an NVIDIA device are available. Without a device it states honestly that the GPU part was not exercised. Local blocks are served by a single device owner.
