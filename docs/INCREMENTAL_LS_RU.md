# Incremental LS-RQAOA (a17)

`IncrementalLSRQAOACPU` — CPU-сборка локального поиска с отдельными
понятиями:

- **где получены новые наблюдения** — `refresh_all` или
  `survivor_neighbor_cover_v1`;
- **какие старые наблюдения разрешено использовать** — банк
  `current_epoch_only` или `keep_unobserved(max_age_steps)`;
- **как выбрать ограничение** — четыре правила score.

## Эпоха

Для текущего `G_t` строится план задач, выполняется полный барьер,
считается среднее по всем завершённым задачам:

\[
\widehat c^{new}_{t,e}
=\frac{\sum_a c^{(a)}_{t,e}}{d_{t,e}}.
\]

Суммы очищаются один раз до всей эпохи; rounds не делят denominator.
Настоящий ноль сохраняется, отсутствующая пара имеет `mask=false`.
Одно ограничение применяется только после полного барьера.

## Банк и возраст

`age_steps=t-observed_epoch`. `keep_unobserved` сохраняет пару, если
она не наблюдалась в новой эпохе и `age_steps <= max_age_steps`;
новое наблюдение заменяет старое, включая ноль. Пара с удалённым
endpoint исключается. Старое `c` не переписывается и не пересчитывается
по новому весу; score всегда считается по текущему весу.

## Score

| rule | score |
|---|---|
| `max_abs_correlation` | `abs(c)` |
| `max_abs_weighted_correlation`, q=1 | `abs(w)*abs(c)` |
| `max_abs_weighted_correlation`, q=2 | `abs(w)^2*abs(c)` |
| `min_signed_edge_product` | `w*c` (минимум) |

Знак ограничения — `sign(c)`, при `c=0` — `zero_sign`; знак веса не
умножает σ. Направление редукции по умолчанию: удалить меньший label,
оставить больший. Score — не корреляция и не вероятность.

## Частичное обновление

`survivor_neighbor_cover_v1` строит блоки вокруг retained-вершины.
Каждый блок содержит center, все прямые соседи покрыты; последний блок
может дополняться 2-hop вершиной только при положительной связности.
Это эвристика, а не утверждение о локальности квантовых корреляций.

## Бюджет

Сначала резервируются все обязательные correlation shots, затем
полные training iterations распределяются round-robin. Если минимум не
помещается, source не запускается; возвращается согласованный fallback.
Exact/analytic source имеет 0 quantum shots, но учитывается CPU cost.

## Ограничения

Нет checkpoint/resume банка, batch-редукций MK_3, odds-fusion,
round-max, energy-prediction, MI-guided selection, GPU, переноса углов
или квантового lift. Старые неверные счётчики не воспроизводятся.
