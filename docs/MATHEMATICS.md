# Математические соглашения

## Взвешенный Max-Cut и энергия

Пусть G=(V,E) — простой неориентированный граф, wᵢⱼ — конечный действительный вес, sᵢ∈{−1,+1}. Для всех алгоритмов определены

\[
C(s)=\sum_{(i,j)\in E}w_{ij}\frac{1-s_i s_j}{2},\qquad
E(s)=-C(s)=\sum_{(i,j)\in E}\frac{w_{ij}}2(s_i s_j-1).
\]

Минимизация E равносильна максимизации C. Постоянная часть −Σw/2 сохранена. Модуль энергии не используется. Отрицательное ребро в разрезе даёт отрицательный вклад в C и положительный в E. Невзвешенный случай задаётся явно через w=1.

Индексы массива определяет `node_order`, а не численное значение метки вершины. Для базисного индекса z бит i соответствует `node_order[i]` и sᵢ=1−2 bitᵢ(z). Это little-endian порядок индекса. На вероятностной диаграмме строки битов развёрнуты так, чтобы **левый символ соответствовал первой вершине**.

## ExactCPU

Публичная задача не имеет локальных полей. Поэтому E(s)=E(−s), и при N>0 первый спин можно зафиксировать равным +1. Алгоритм перебирает 2^(N−1) представителей, находит минимум и максимум C, затем вторым проходом считает число максимумов относительно окончательно найденного C*. Удвоение числа представителей восстанавливает вырождение по глобальной инверсии. Для пустого графа существует единственное пустое решение.

`tie_tolerance` применяется только к подсчёту вырождения; максимум выбирается по наибольшему вычисленному C. Время O(|E|2^N), память рабочего вектора O(batch_size). Термин «точный» означает полный перебор, а не символьную арифметику: веса и суммы представлены float64. Сильная компенсация больших положительных и отрицательных весов может влиять на сравнение близких значений. Итоговое C решения дополнительно проверяется прямым суммированием на исходном снимке графа.

## QAOACPU

Диагональный гамильтониан H_E имеет собственные значения E(z)=−C(z). Миксер B=ΣᵢXᵢ. Начальное состояние |+⟩^N. Для слоя ℓ сначала применяется U_E(γℓ)=exp(−iγℓH_E)=exp(+iγℓC), затем U_B(βℓ)=exp(−iβℓB). Первый слой имеет индекс 0. Вектор параметров хранится как [γ₀,…,γₚ₋₁,β₀,…,βₚ₋₁].

Применение миксера разбито на независимые двухэлементные преобразования, поскольку операторы Xᵢ коммутируют. Оба новых элемента вычисляются из старой пары, что предотвращает использование уже изменённой амплитуды. Полный вектор содержит 2^N комплексных чисел; сжатие по инверсии не применяется. Проверяется норма, затем удаляется только накопленная погрешность нормировки. Область применения — небольшие задачи и будущие подзадачи составных алгоритмов. Возможность создать граф на 1000 вершин не означает возможность симулировать его полный квантовый вектор.

Схема опирается на [Farhi, Goldstone, Gutmann, 2014](https://arxiv.org/abs/1411.4028). Из-за выбора H_E=−C знак γ относительно формулировок со схемой exp(−iγC) противоположен. Для единственного ребра w=1, p=1:

\[
\langle C\rangle=\frac{1-\sin(\gamma)\sin(4\beta)}2.
\]

При γ=−π/2 и β=π/8 получаются ⟨C⟩=1, ⟨E⟩=−1, ⟨Z₀Z₁⟩=−1. Этот случай и независимое плотное матричное произведение для p=1,2 входят в проверки.

## Критерии распределения

Пусть Pθ(z)=|ψθ(z)|², значения C упорядочены по возрастанию как cᵣ, их массы pᵣ. Все критерии F ниже **максимизируются**. Оптимизатор получает L=−F. Для Mean Cut L=⟨E⟩; у других критериев L не является обычным математическим ожиданием физической энергии.

| type | F и параметры | Единицы |
|---|---|---|
| `mean_cut` | Σ pᵣcᵣ | Вес разреза |
| `cvar` | Среднее C в лучших α долях вероятностной массы; 0<α≤1 | Вес разреза |
| `gibbs` | log(Σ pᵣ exp(ηcᵣ))/η; η>0 | Вес разреза; η имеет обратные единицы |
| `best_of_k` | E[max(C₁,…,C_K)] для K независимых выборок; K≥1 целое | Вес разреза |
| `threshold_probability` | P(C≥A), параметр `threshold=A` | Безразмерная вероятность |

CVaR берёт ровно массу α, включая дробную часть граничного состояния, а не целое число лучших состояний. В энергетической нотации это минус нижнехвостовой CVaR энергии. Обоснование применения CVaR к вариационной оптимизации: [Barkoutsos et al., 2020](https://quantum-journal.org/papers/q-2020-04-20-256/).

Для Best-of-K используется CDF: P(max≤cᵣ)=F_C(cᵣ)^K, откуда масса максимума равна разности соседних значений этой степени. Повторяющиеся значения c допустимы. Gibbs вычисляется через `logsumexp`, чтобы не экспонировать большие значения непосредственно. Threshold Probability использует абсолютный порог C, что равносильно E≤−A; это не порог нормированного качества.

## Оценка, градиент, readout и бюджет

В `exact` F вычисляется по полной Pθ. В `shots` для каждой оценки выполняются M независимых выборок, строится эмпирическая масса и к ней применяется тот же F. Для нелинейных критериев это подстановочная оценка; она не обязана быть несмещённой. Градиент вычисляется центральными разностями [L(θ+heᵢ)−L(θ−heᵢ)]/(2h), с отдельными выборками для каждого пробного вектора. При d=2p один полный шаг требует 2d+1 оценок, включая центр. Малое h при шотовой оценке может усиливать шум.

Далее применяется ADAM с коррекцией смещения первого и второго моментов, согласно [Kingma, Ba, 2014](https://arxiv.org/abs/1412.6980). Обновление последнего шага не обязательно оценивается: readout использует лучший **уже оценённый** вектор, включая точки градиентных проб. `optimizer_history` хранит центры шагов; `objective_history` при включении хранит все оценки. Их лучший элемент может различаться.

`most_probable` выбирает индекс с наибольшей точной вероятностью; при равенстве выбирается первый индекс. Он не расходует измерительные шоты и доступен здесь потому, что используется классический симулятор. `best_of_shots` выполняет ровно M конечных выборок и выбирает наибольшее C среди них. Это отдельная операция от тренировочных шотов.

Перед началом обучения резервируется весь конечный readout. Новый градиентный шаг начинается, только если бюджет позволяет выполнить его целиком и сохранить резерв. Поэтому `shots_used≤limits.shots_total`. Если хватает только на readout, обучение не выполняется, `objective_value=None`, начальные углы сохраняются и решение всё равно возвращается. Недостаточный бюджет самого readout отклоняется до расчёта.

`expected_cut` и `expected_energy` — точные ожидания конечного симулированного состояния даже при шотовом обучении; происхождение обозначено как `expected_cut_source="exact_final_statevector"`. `objective_value` — лучшая тренировочная оценка; при режиме shots это случайная оценка, выбранная среди многих проб. Её нельзя выдавать за независимую точную оценку качества.

## Корреляции и сравнение

`correlation_matrix` возвращает физические Mᵢⱼ=⟨ZᵢZⱼ⟩=1−2P(bitᵢ≠bitⱼ), Mᵢᵢ=1. Корреляция может быть отрицательной и не является вероятностью: P(sᵢ=sⱼ)=(1+Mᵢⱼ)/2.

Если для той же задачи известны C* и C_min, `quality_score` вычисляет q=(C−C_min)/(C*−C_min). При нулевом знаменателе возвращается `None`. Это удобная нормировка для знаковых весов; она не заявляется approximation ratio GW. Неизвестный точный оптимум нельзя подменять им при сравнении с эвристическим ориентиром.

## Карты

`scan_landscape` рассчитывает точную p=1 сетку: строки соответствуют β, столбцы γ. По умолчанию сохраняется `optimizer_loss`, то есть ⟨E⟩ для Mean Cut. Альтернатива `quantity="objective_value"` сохраняет F. Окна γ и β задаются явно: для произвольных действительных весов не предполагается универсальный период по γ. Расчёт карты не запускает оптимизацию и не меняет результат солвера.
