# Статус 0.1.0a2

Версия 0.1.0a2 добавляет к первому CPU-этапу **точное ядро парных редукций**
Max-Cut → Изинг. Это самостоятельный математический компонент для будущих
RQAOA и LS-RQAOA; сами эти алгоритмы ещё не реализованы.

## Ядро редукций

Реализовано:

- перевод взвешенного Max-Cut в Изинг с `J=w/2`, `h=0`, `c=-Σw/2`;
- парное ограничение `s_u = σ s_v` для произвольных (в том числе несмежных) пар;
- точное равенство энергии для всех назначений остатка;
- накопленный сдвиг `b_t` и полная константа `c_t` как разные величины;
- обратное восстановление исходных номеров, включая цепочки, где сохранённая
  вершина удаляется позже;
- компактная трасса события: вес, корреляция, score, `fixed_energy`,
  `expected_fixed_energy`, `Δb`, `Δc`, структурная статистика;
- JSON-совместимый снимок математического состояния и продолжение после
  `from_snapshot`;
- атомарность ошибочного запроса: состояние не меняется.

Ограничения этапа:

- нет абсолютной фиксации одного спина;
- нет выбора пары и источника корреляций;
- нет RQAOA/LS-RQAOA поверх ядра;
- снимок не является checkpoint/resume оптимизатора;
- поля поддерживаются в `IsingProblem`, но публичный `solve(graph)` по-прежнему
  принимает только граф без полей.

## Основание для переноса

Исходный архив содержит 89 Python-файлов и 25 548 строк. Инвентарь файлов и
классов приложен в `reference/source_inventory.json`. Полная согласованная
архитектура приложена отдельно. Наличие файла в инвентаре не означает, что
соответствующий алгоритм уже перенесён.

## Дальнейшая последовательность

1. Подключить проверенное ядро к заменяемым источникам корреляций, выбору пары
   и завершающему солверу; собрать базовый RQAOA.
2. Перенести LS-построители подграфов и энергетические трассы редукций.
3. Перенести QAOA-in-QAOA и экспериментальные стратегии, сохраняя происхождение
   каждого варианта.
4. Добавить независимые GPU-реализации, CPU-пулы и измеряемый профилировщик.
5. Завершить общий бенчмарк, контрольные точки и полный комплект
   интерактивных графиков.

Отсутствующие возможности не заменены заглушками с успешным статусом.
