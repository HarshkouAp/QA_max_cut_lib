# Статус 0.1.0a1

Этот этап проверяет общий интерфейс на двух законченных CPU-алгоритмах. Это основа для переноса архива, а не заявление о готовности всех согласованных возможностей.

| Область | В этой сборке | Следующий объём работ |
|---|---|---|
| Граф | Изменяемый `WeightedGraph`, исходные целые номера, пропуски, отрицательные/нулевые веса, снимок и fingerprint | Дополнительные операции по потребностям редукций |
| Solvers | `ExactCPU`, полный вектор состояния `QAOACPU`, общий lifecycle, JSON и прямые атрибуты | GW, RQAOA, LS-RQAOA, QAOA-in-QAOA; сопоставление с исходными версиями |
| Сборка алгоритмов | Общие контракты, конфигурации и реестр двух солверов | Независимые источники корреляций, построители подграфов, правила редукции и завершающие солверы |
| QAOA | ADAM, центральные разности, p слоёв, пять критериев, точная/шотовая оценка, два режима readout | Другие оптимизаторы и режимы из архива |
| GPU | Только отдельные профили зависимостей | Самостоятельные GPU-алгоритмы и численная сверка с CPU |
| Generators | Complete, G(n,m), G(n,p), три генератора весов, индуцированные подграфы, случайное разбиение | Исследовательские генераторы и стратегии подграфов из архива |
| Tools | Корреляции, нормированное качество при известных обоих экстремумах, статические графики, точная карта p=1 | GW/лучшее известное решение, большие вероятностные диаграммы, интерактивные 3D HTML |
| Редукции | Не реализованы | Трасса редукций, энергетические вклады, все попарные траектории углов, веса рёбер |
| Laboratory | Имена будущего модуля зарезервированы; экспериментальных солверов нет | Все содержательно разные версии из архива через заменяемые компоненты |
| Серии | Можно вручную собирать независимые `RunRecord` | Общий планировщик бенчмарков, свип конфигураций, resume серии |
| Параллелизм | Явный `num_treads=1`; другие значения отклоняются | Параллельные подграфы LS и QAOA-in-QAOA, учёт вложенных пулов |
| Профилировщик | Не реализован | Весь диапазон конфигураций, свип потоков, измерения времени, модель Амдала |
| Бюджеты | Строгий общий бюджет шотов QAOA и число шагов ADAM | Иерархический учёт ресурсов составных алгоритмов |
| Контрольные точки | Включение `checkpoint.enabled` отклоняется | Версионированное состояние оптимизатора, RNG, редукций и планировщика |
| Результат/экспорт | JSON, ndarray/complex, NPY, выбор атрибутов, снимки, защита от перезаписи | Сериализаторы специальных объектов других алгоритмов |
| Оформление | Seaborn + Computer Modern/MathText; настройка настоящего LaTeX | Проверка настоящего LaTeX в полной TeX-среде, единый автономный HTML |
| Документация | Два выполненных ноутбука, справочник текущего API, математика, Sphinx/numpydoc | Расширение одновременно с каждым перенесённым алгоритмом |

## Основание для переноса

Исходный архив содержит 89 Python-файлов и 25 548 строк. Инвентарь файлов и классов приложен в `reference/source_inventory.json`. Полная согласованная архитектура приложена отдельно. Наличие файла в инвентаре не означает, что соответствующий алгоритм уже перенесён.

Первый CPU QAOA реализован заново с явным знаком гамильтониана и проверкой через независимые плотные матрицы. Он не объявляется численно тождественным каждой исследовательской версии. Для переноса конкретной версии потребуется сверить её критерий, схему, градиент, начальные точки, readout и учёт ресурсов.

## Дальнейшая последовательность

1. Выделить и проверить общий редуктор Изинга с константой энергии и восстановлением решения.
2. Подключить источники корреляций, завершающие солверы и RQAOA; проверить энергии до/после каждой редукции.
3. Перенести LS и QAOA-in-QAOA, затем экспериментальные стратегии, сохраняя происхождение каждого варианта.
4. Добавить независимые GPU-реализации, CPU-пулы и измеряемый профилировщик.
5. Завершить общий бенчмарк, контрольные точки и полный комплект интерактивных графиков.

Эта последовательность сохраняет ранее согласованный состав библиотеки. Отсутствующие возможности не заменены заглушками с успешным статусом.
